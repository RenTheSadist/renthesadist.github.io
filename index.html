✨ What Is MosaicDiff?

MosaicDiff is a desktop application that helps you clean up images that have been blurred, pixelated, or covered with a mosaic pattern. Whether a picture was intentionally obscured, damaged during compression, or simply came out too soft, MosaicDiff analyzes the visible information and rebuilds the missing detail so the picture looks natural again.

Under the hood, MosaicDiff runs on MiniMax H3, a modern image generation engine, and pairs it with a custom LoRA — a small, focused add-on model that teaches the software exactly what restored photos should look like. You do not need to understand any of that to use it. You simply open your picture, choose how strong the repair should be, and let the app do the work.

The result is a tool that behaves like a normal Windows program: a window, a few buttons, and a folder of finished images. No command lines, no configuration files, and no programming knowledge required.

🎯 What You Can Do With It

  • Restore mosaic areas on photos where a region has been intentionally pixelated.
  • Recover soft detail in pictures that look blurry after being resized or compressed.
  • Process a whole folder of images in one go instead of opening them one by one.
  • Control the strength of the repair with a simple slider, from a light touch-up to a full rebuild.
  • Compare before and after side by side inside the app before you save anything.
  • Keep your originals safe — MosaicDiff always writes results to a new file.
  • Work with common formats such as JPG, PNG, and WebP.

🚀 Your First Restored Image

Once MosaicDiff is open, the main window guides you through three simple areas: where your image comes from, how strong the repair should be, and where the finished picture goes.

  1. Add your image. Drag a picture into the window, or use the add button to browse your folders. You can select several images at once.
  2. Preview the mosaic area. The app highlights the regions it believes need repair. If a spot was missed, use the brush control to mark it yourself.
  3. Choose a strength. Start with the middle setting. A lower value keeps more of the original look; a higher value rebuilds more detail.
  4. Run the restoration. Press the start button and watch the progress bar. A single photo usually finishes in under a minute on a computer with a dedicated graphics card.
  5. Compare the result. Use the before-and-after view to check the work. If it looks too strong or too soft, adjust the slider and run it again.
  6. Save your result. Choose an output folder and confirm. Your new image is saved with a separate file name, so the original stays untouched.

🧠 Getting Better Results

A few small habits make a noticeable difference in quality:

  • Start from the largest version you have. More visible pixels give the model more to work with.
  • Repair one region at a time. Large mosaic blocks across an entire image are harder than a small covered area.
  • Use moderate strength first. You can always run a second pass at a higher setting.
  • Keep faces and text realistic. Those areas benefit from a lower strength, because over-processing makes them look artificial.
  • Save as PNG when you plan to edit the result further, so no extra compression is added.

🛠️ Troubleshooting

The download is very slow or stops

Pause any other large downloads and try again. Wired or strong Wi-Fi connections are more reliable than mobile hotspots for big files.

Windows shows a security warning

This happens for many applications that are downloaded rather than bought from a store. Confirm that you downloaded from the link on this page, then allow the app to run.

The app opens but feels sluggish

Close other heavy programs, then try again with a smaller image. On laptops, plugging in the power adapter often unlocks full performance.

The result looks too smooth or too sharp

Lower the strength setting for a more natural finish, or raise it slightly if detail is still missing. Running the same image twice at a moderate setting also helps.

An image will not load

Convert it to a standard JPG or PNG first. Unusual formats and very large files above the recommended size can be refused by the app.

🔧 How It Works Inside

MosaicDiff combines two well-known ideas. First, it detects where information has been lost — the tell-tale grid of a mosaic, or the softness left by heavy compression. Second, it asks the MiniMax H3 engine to draw plausible detail into those gaps, guided by the surrounding pixels so the repaired area matches its neighbours in color, texture, and lighting.

The custom LoRA is the part that makes the output look natural rather than artificial. It is a small companion model trained specifically for restoration work, which nudges the engine toward believable skin, fabric, foliage, and background texture instead of invented patterns. Because the LoRA is lightweight, it adds barely any extra time to each image while noticeably improving the final look.

All of this happens automatically. The only decisions left to you are which picture to fix, how strong the repair should be, and where to save the result.
